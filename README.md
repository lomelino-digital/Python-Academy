# Python Academy

This repository is for Python Academy, a Python learning-in-public project.

As this is also my Git learning experience, there are some choices I haven't seen in other repositories.

Namely, each chapter in my Python learning is getting its own branch. This started as a way for me to learn branches, but also became a way that anyone — future me most likely — can easily inspect my progress, comments, mistakes, and changes in mindset.

The `main` branch will have anything I find useful to download and use.

## Automate the buring stuff with Python

I'm starting with *Automate the Boring Stuff with Python* and building small projects alongside each chapter, with the goal of eventually producing a larger final graduation project as a deliverable — ideally a tool I can actually use myself or that may be useful to others.

For each chapter, I write all the exercises by hand and make modifications I find interesting. I also produce a new iteration of a personal project, constrained to the material covered in the chapters studied so far.

Each chapter of the book has its own Git branch. This is also part of the learning process, since I'm currently learning Git. The `main` branch will contain the deliverables I find useful, while the chapter branches provide a glimpse into the learning process and how the projects evolve.

## AI Tutors

I'm also building AI tutors to help me learn and identify weak points.

The tutors can be pasted into a chatbot or saved as a GPT, Gem, or project. They have a checkpoint function that produces an output which can be carried into other sessions or used with other tutors to help maintain continuity.
