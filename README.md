# Python Academy

Python Academy is a Python learning-in-public project.

This repository documents both what I build and how I learn. It is also my Git learning experience, so some of its choices are deliberately educational.

The `main` branch contains work I find useful to preserve, share, or use independently.

## Learning Paths and Resources

My learning combines structured study, practical exercises, external training, and independent programming challenges.

## Projects and Practical Work

I work through exercises by hand, experiment with modifications, and build projects alongside what I learn. Where possible, I develop projects incrementally, using only the concepts covered so far.

The goal is to develop practical skills and eventually produce tools I can use myself or that may be useful to others.

## Tools for Independent Learning

The [`python-academy-project/`](./python-academy-project/) directory hosts tools and resources that others can download and use to support their own learning.

This includes AI tutors designed to help learners identify weak points and maintain continuity across learning sessions. The tutors can be pasted into a chatbot or saved as a GPT, Gem, or project. They include a checkpoint function that produces an output that can be carried into other sessions or shared with other tutors to maintain continuity.

## Learning in Public

This is an ongoing learning project, not a collection of finished, production-ready software.

The code may contain beginner-level solutions, experiments, mistakes, and alternative approaches. These are part of the process, not something to hide.

The objective is to build practical skills, preserve useful work, and make progress visible over time.
