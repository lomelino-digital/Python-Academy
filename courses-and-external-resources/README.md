# Courses and External Resources

This directory contains Python exercises and practical work completed through
external learning resources, formal training, and programming challenges.

The goal is to document learning in public and build a record of practical work
over time using resources outside the Python Academy bibliography or self-created challenges

## Contents

### [SoloLearn](./sololearn/)

Python exercises and community challenges completed through the SoloLearn app.

This section provides a place to preserve solutions, explore different
approaches, and track progress through independent practice.

### [UC00245-02 — Developing Algorithms](./uc00245-developing-algorithms/)

Practical exercises and projects completed as part of formal Python training
in Portugal.

The directory is organized by training session, with a separate directory
for the final project.

The official course title is **UC00245 - Desenvolver algoritmos. See the course README for the training details.

## Learning Approach

This collection focuses on practical learning and evidence of work.

The exercises are organized according to their original learning context.
Alternative implementations and intermediate attempts may be preserved when
they help document the learning process.

The code in this directory is part of an ongoing learning journey. It may
contain beginner-level solutions and is not intended to represent production-
ready software.

## Repository Conventions

- Python exercises are organized by their learning source.
- Formal coursework follows the training session structure.
- Course-provided PDF and DOCX documents are excluded from version control.
- Solutions and notes are maintained as part of the learning process.

## Purpose

The objective is to build a public record of practical programming experience:
not only what was studied, but also what was implemented, tested, debugged,
and learned along the way.
