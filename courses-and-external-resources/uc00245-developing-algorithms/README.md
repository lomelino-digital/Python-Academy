# UC00245 — Desenvolver algoritmos

**English title:** Developing Algorithms

This directory documents practical exercises and project work completed
as part of formal Python training in Portugal.

The course focuses on developing algorithms using construction techniques,
diagrammatic representation tools, and Python.

## Course Information

| Field | Details |
|---|---|
| Official course title | UC00245 - Desenvolver algoritmos (2024\|2027) |
| Training provider | EISNT Tecnologia |
| Duration | 25 hours |
| Delivery format | Distance learning — group-based e-learning |
| Programming language | Python |

## Programme Summary

The official programme covers:

- Developing algorithms by applying construction techniques.
- Using applications for diagrammatic representation.
- Ensuring that the problem is solved.
- Using Python as the programming tool for the unit.
